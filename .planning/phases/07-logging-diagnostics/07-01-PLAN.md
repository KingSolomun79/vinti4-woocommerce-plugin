  <name>Task 1: Create Vinti4_Logger class</name>
  <files>includes/class-vinti4-logger.php</files>
  <action>
Create `includes/class-vinti4-logger.php` with class `Vinti4_Logger`.

The class must:

1. Have a private static `$debug` bool property, default `false`.

2. **`public static function init( WC_Gateway_Vinti4 $gateway ): void`**
   - Sets `self::$debug` to `true` if `$gateway->debug` is `'yes'`, otherwise `false`.

3. **`public static function log( string $message, string $level = 'debug' ): void`**
   - If `self::$debug` is false, return immediately (no logging).
   - Call `wc_get_logger()->log( $level, $message, array( 'source' => 'vinti4' ) )`.
   - The 'source' parameter makes logs appear under WooCommerce → Status → Logs with source "vinti4".

4. **`public static function mask_auth_code( string $code ): string`**
   - If empty string, return empty string.
   - If length < 6: return first char + asterisks for remaining (e.g. "A***" for "Abcd").
   - If length >= 6: return first 3 chars + asterisks for middle + last 2 chars (e.g. "ABC***YZ" for "ABCDEFGHYZ").
   - Number of asterisks = total length - 5 (for >= 6) or total length - 1 (for < 6).

5. **`public static function is_enabled(): bool`**
   - Returns `self::$debug`.

Standard plugin header guard: `defined( 'ABSPATH' ) || exit;` and `if ( class_exists( 'Vinti4_Logger' ) ) { return; }`.

No external dependencies. Use only WordPress/WooCommerce built-in functions.
  </action>
  <verify>PHP syntax check: `php -l includes/class-vinti4-logger.php` returns no errors</verify>
  <done>Vinti4_Logger class exists with init(), log(), mask_auth_code(), and is_enabled() methods. mask_auth_code("ABCDEFGHYZ") returns "ABC***YZ". mask_auth_code("Abcd") returns "A***".</done>
