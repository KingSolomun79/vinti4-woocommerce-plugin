<?php
defined( 'ABSPATH' ) || exit;

**Static `register()` method** — called from bootstrap during `plugins_loaded`:
- `add_action( 'add_meta_boxes', [ __CLASS__, 'add_meta_box' ] )`
- `add_action( 'wp_ajax_vinti4_create_partial_request', [ __CLASS__, 'handle_create_partial_request' ] )`

**Static `add_meta_box()` method**:
- Call `add_meta_box( 'vinti4_partial_payment', 'Vinti4 Payment Requests', [ __CLASS__, 'render_meta_box' ], 'shop_order', 'side', 'high' )`
- Also register for `'woocommerce_page_wc-orders'` screen (HPOS compatibility) using the same callback

**Static `render_meta_box( WP_Post $post )` method** (accepts $post but uses order ID):
- Resolve order: `$order = wc_get_order( $post->ID ?? $post )` — handle both WP_Post and direct ID for HPOS
- Guard: if not a valid order, show "Order not found" and return
- Get outstanding: `$outstanding = Vinti4_Attempt_Store::get_outstanding_total( $order )`
- Get paid: `$paid = Vinti4_Attempt_Store::get_paid_total( $order )`
- Get order total: `(float) $order->get_total()`

Render the following HTML inside the meta box (all strings wrapped in `__()` with text domain `'vinti4'`):

1. **Balance summary** — a small table with three rows:
   - "Order Total:" + formatted wc_price($order_total)
   - "Paid:" + formatted wc_price($paid)
   - "Outstanding:" + formatted wc_price($outstanding) — highlighted with `font-weight:bold; color:#2271b1` when > 0

2. **If outstanding <= 0**: show "This order is fully paid." message and return early (no form)

3. **Payment request form** (wrapped in a div with class `vinti4-partial-form`):
   - wp_nonce_field with action `'vinti4_partial_payment'` and name `'vinti4_partial_nonce'`
   - Hidden input `name="vinti4_order_id"` with value `$order->get_id()`
   - Radio group for mode:
     - `<input type="radio" name="vinti4_amount_mode" value="fixed" checked>` + label "Fixed Amount"
     - `<input type="radio" name="vinti4_amount_mode" value="percentage">` + label "Percentage (%)"
   - Text input `name="vinti4_partial_amount"` with placeholder "Enter amount"
   - Submit button: class `button button-primary` with text "Create Payment Request"

4. **Error message area**: empty `<div class="vinti4-partial-error" style="color:#8B0000;margin-top:8px"></div>`

5. **Payment link area** (hidden initially): `<div class="vinti4-payment-link-area" style="display:none;margin-top:12px">` containing:
   - Label "Payment Link:"
   - A readonly text input with the generated URL
   - A "Copy Link" button (class `button`)

6. **Inline JavaScript** (wrapped in `<script>` tag):
   - On form submit: prevent default, validate amount is non-empty and numeric client-side, show error if invalid
   - Build AJAX POST to `ajaxurl` (WordPress global) with:
     - `action: 'vinti4_create_partial_request'`
     - `vinti4_partial_nonce`: from the nonce field value
     - `vinti4_order_id`: from the hidden field
     - `vinti4_amount_mode`: from checked radio
     - `vinti4_partial_amount`: from input
   - On success response: show payment link area, populate the URL input with `response.data.payment_link`
   - On error response: show `response.data.message` in error area
   - Copy Link button: select the input text and call `navigator.clipboard.writeText()`, briefly change button text to "Copied!"
   - Style: add a small `.vinti4-partial-form table { width:100% } .vinti4-partial-form td { padding:2px 4px; }` inline style block

**Static `handle_create_partial_request()` method** — the AJAX handler:

1. `check_ajax_referer( 'vinti4_partial_payment', 'vinti4_partial_nonce' )` — dies on failure
2. `if ( ! current_user_can( 'manage_woocommerce' ) ) { wp_send_json_error( [ 'message' => 'Unauthorized.' ] ); }`
3. Read and sanitize POST inputs:
   - `$order_id = absint( $_POST['vinti4_order_id'] ?? 0 )`
   - `$mode = sanitize_text_field( wp_unslash( $_POST['vinti4_amount_mode'] ?? 'fixed' ) )`
   - `$raw_amount = sanitize_text_field( wp_unslash( $_POST['vinti4_partial_amount'] ?? '' ) )`
4. Load order: `$order = wc_get_order( $order_id )` — if not valid, return error "Order not found."
5. Validate amount input is numeric: `if ( ! is_numeric( $raw_amount ) )` → error "Please enter a valid number."
6. Compute requested amount based on mode:
   - If `$mode === 'percentage'`:
     - `$percentage = (float) $raw_amount`
     - Validate: `$percentage <= 0 || $percentage > 100` → error "Percentage must be between 1 and 100."
     - `$outstanding = Vinti4_Attempt_Store::get_outstanding_total( $order )`
     - `$amount = round( $outstanding * ( $percentage / 100 ), 2 )`
   - Else (fixed):
     - `$amount = (float) $raw_amount`
7. Validate: `$amount <= 0` → error "Amount must be greater than zero."
8. Get outstanding: `$outstanding = Vinti4_Attempt_Store::get_outstanding_total( $order )`
9. Validate: `$outstanding <= 0.01` → error "This order is already fully paid."
10. Validate: `$amount > $outstanding + 0.01` → error "Amount cannot exceed the outstanding balance of [formatted amount]."
11. Get gateway instance:
    ```php
    $gateways = WC()->payment_gateways()->get_available_payment_gateways();
    $gateway = $gateways['vinti4'] ?? null;
    if ( ! $gateway ) { wp_send_json_error( [ 'message' => 'Vinti4 gateway is not available.' ] ); }
    ```
12. Create attempt:
    ```php
    $attempt = $gateway->create_payment_attempt( $order, $amount, [ 'source' => 'admin_partial' ] );
    Vinti4_Attempt_Store::append_attempt( $order, $attempt, true );
    ```
13. Generate payment link:
    ```php
    $payment_link = add_query_arg(
        [ 'order' => $order->get_id(), 'key' => $order->get_order_key() ],
        home_url( '/vinti4-payment/' )
    );
    ```
14. Add order note:
    ```php
    $order->add_order_note( sprintf(
        'Vinti4 partial payment request created: %s. Outstanding was: %s.',
        wc_price( $amount ), wc_price( $outstanding )
    ) );
    ```
15. Log:
    ```php
    Vinti4_Logger::log( sprintf(
        'Admin partial request: order %d, amount %.2f, attempt %s',
        $order->get_id(), $amount, $attempt['attempt_id'] ?? 'unknown'
    ) );
    ```
16. Return success:
    ```php
    wp_send_json_success( [
        'payment_link' => $payment_link,
        'amount'       => $amount,
        'attempt_id'   => $attempt['attempt_id'] ?? '',
    ] );
    ```

Follow existing codebase conventions:
- Use Yoda conditions (`'fixed' === $mode`)
- Use `wp_unslash()` on input
- Use `sanitize_text_field()` for string inputs
- Use `absint()` for integer inputs
- All user-facing strings in `__()` with `'vinti4'` text domain
- No comments in code
