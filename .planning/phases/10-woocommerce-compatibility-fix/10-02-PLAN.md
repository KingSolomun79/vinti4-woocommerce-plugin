  <name>Task 1: Add attempt history table and payment progress display to meta box</name>
  <files>includes/class-vinti4-admin-partial-payment.php</files>
  <action>
Extend the `render_meta_box()` method in `Vinti4_Admin_Partial_Payment`. Add the following BEFORE the payment request form section (after the balance summary, before the form):

**Attempt History Section:**
- Get attempts: `$attempts = Vinti4_Attempt_Store::get_attempts( $order )`
- If attempts array is not empty, render a section with heading "Payment History" containing a table:
  - Columns: # (sequence), Amount, Status, Date, Reference
  - For each attempt, render a table row:
    - Sequence: `$attempt['sequence'] ?? ''`
    - Amount: `wc_price( $attempt['amount'] ?? 0 )` (note: amount is stored as normalized integer from request builder, so display as `wc_price( (float) ( $attempt['amount'] ?? 0 ) )`)
    - Status: use a colored badge:
      - `'completed' === ($attempt['status'] ?? '')` → green "Paid" badge
      - `'failed' === ($attempt['status'] ?? '')` → red "Failed" badge
      - Otherwise → amber "Pending" badge
    - Date: `$attempt['created_at_gmt'] ?? ''` (formatted as human-readable)
    - Reference: truncated `$attempt['merchant_ref'] ?? ''` (last 12 chars, in a `<code>` tag)
  - Wrap the table in `<table class="widefat fixed striped" style="margin-top:8px;font-size:12px">`
  - After the table, add a "Generate Payment Link" link/button for each pending attempt that re-projects that attempt to legacy meta so the admin can resend it. This is a small link that triggers an AJAX call to re-project:
    - Create a new AJAX action `vinti4_reproject_attempt` in the register() method
    - The handler: verify nonce + capabilities, load order, find attempt by attempt_id from POST, call `Vinti4_Attempt_Store::project_latest_attempt_to_legacy_meta( $order, $attempt )`, `$order->save()`, return payment link URL
    - Each pending row gets a "Resend Link" link that calls this AJAX

**Payment Progress Bar:**
After the balance summary table, add a visual progress indicator:
- Calculate `$progress_percent = $order_total > 0 ? round( ( $paid / $order_total ) * 100, 1 ) : 0`
- Render a simple CSS progress bar:
  ```html
  <div style="background:#e0e0e0;border-radius:4px;height:8px;margin:4px 0 8px">
    <div style="background:#2271b1;height:8px;border-radius:4px;width:<?php echo esc_attr( $progress_percent ); ?>%"></div>
  </div>
  <small><?php echo esc_html( $progress_percent ); ?>% paid</small>
  ```

**Re-project AJAX handler** — add to the `register()` method:
- `add_action( 'wp_ajax_vinti4_reproject_attempt', [ __CLASS__, 'handle_reproject_attempt' ] )`

**Static `handle_reproject_attempt()` method:**
1. `check_ajax_referer( 'vinti4_partial_payment', 'vinti4_partial_nonce' )`
2. Capability check: `current_user_can( 'manage_woocommerce' )`
3. `$order_id = absint( $_POST['vinti4_order_id'] ?? 0 )`
4. `$attempt_id = sanitize_text_field( wp_unslash( $_POST['vinti4_attempt_id'] ?? '' ) )`
5. Load order, validate
6. Find attempt in history: iterate `Vinti4_Attempt_Store::get_attempts( $order )` matching `attempt_id`
7. If found, call `Vinti4_Attempt_Store::project_latest_attempt_to_legacy_meta( $order, $attempt )`
8. `$order->save()`
9. Generate payment link: `add_query_arg( [ 'order' => $order->get_id(), 'key' => $order->get_order_key() ], home_url( '/vinti4-payment/' ) )`
10. `wp_send_json_success( [ 'payment_link' => $payment_link ] )`
11. If not found: `wp_send_json_error( [ 'message' => 'Attempt not found.' ] )`

**Add reproject JS to inline script:**
Add a function `vinti4ReprojectAttempt(attemptId, orderId, nonce)` that POSTs to `ajaxurl` with action `vinti4_reproject_attempt`, shows the returned payment link.

Style the "Resend Link" links in each attempt row: `<a href="#" onclick="vinti4ReprojectAttempt(...)">Resend</a>`

Follow existing codebase conventions: Yoda conditions, wp_unslash, sanitize_text_field, __() with 'vinti4' text domain, no comments.
