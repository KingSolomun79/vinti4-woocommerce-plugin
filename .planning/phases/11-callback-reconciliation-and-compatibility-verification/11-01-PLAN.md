<objective>
Refactor callback handler to resolve and validate at attempt granularity while tracking paid/outstanding totals across multiple payment attempts.

Purpose: Current callback handler validates against order-level legacy metadata and has order-level idempotency, which blocks partial payments from admin flow. This plan adds attempt-level resolution, per-attempt idempotency, and partial payment totals tracking.

Output: Callback handler that resolves attempts from history, validates per-attempt idempotency, fails safely with diagnostic logs, and accurately tracks paid/outstanding totals.
</objective>

<task type="auto">
  <name>Add attempt lookup and paid/outstanding totals tracking to Attempt_Store</name>
  <files>includes/class-vinti4-attempt-store.php</files>
  <action>
    1. Add static method find_attempt_by_merchant_ref(WC_Order $order, string $merchant_ref): ?array:
       - Get attempts via get_attempts($order)
       - Iterate and return the attempt where attempt['merchant_ref'] === $merchant_ref
       - Return null if not found
       - Log via Vinti4_Logger if not found: "Attempt lookup failed: merchantRef {merchant_ref} not in order {order_id} history"

    2. Add static method get_paid_total(WC_Order $order): float:
       - Get attempts via get_attempts($order)
       - Filter attempts where attempt['status'] === 'completed' or attempt['callback_received'] === true
       - Sum the attempt['amount'] values (convert to float and sum)
       - Store result in order meta _vinti4_paid_total for caching
       - Return the sum as float

    3. Add static method get_outstanding_total(WC_Order $order): float:
       - Get order total via $order->get_total()
       - Get paid total via get_paid_total($order)
       - Return max(0, order_total - paid_total)

    4. Add static method mark_attempt_completed(WC_Order $order, string $attempt_id, string $transaction_id): void:
       - Get attempts via get_attempts($order)
       - Find the attempt with matching attempt_id
       - Update attempt array to set status='completed' and transaction_id=$transaction_id
       - Update _vinti4_attempt_history meta with modified array
       - Update _vinti4_paid_total meta by calling get_paid_total($order)
       - Save order

    5. Add static method mark_attempt_failed(WC_Order $order, string $attempt_id, string $error_message): void:
       - Get attempts via get_attempts($order)
       - Find the attempt with matching attempt_id
       - Update attempt array to set status='failed' and error=$error_message
       - Update _vinti4_attempt_history meta with modified array
       - Save order
  </action>
  <verify>

    - get_paid_total() sums completed attempts and caches result
    - get_outstanding_total() returns order_total - paid_total
    - mark_attempt_completed() and mark_attempt_failed() update attempt status in history
  </verify>
  <done>

  </done>
