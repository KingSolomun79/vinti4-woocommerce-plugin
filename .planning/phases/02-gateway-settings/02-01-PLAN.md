<task type="auto">
  <name>Task 2: Override process_admin_options() for auth code sanitization and load settings into properties</name>
  <files>includes/class-wc-gateway-vinti4.php</files>
  <action>
    **A. Override `process_admin_options()` method** — Add this new method AFTER `init_form_fields()` and BEFORE `process_payment()`:

    ```php
    public function process_admin_options() {
        parent::process_admin_options();

        $post_key = 'woocommerce_' . $this->id . '_pos_auth_code';
        if ( isset( $_POST[ $post_key ] ) ) {
            $this->update_option( 'pos_auth_code', wp_unslash( $_POST[ $post_key ] ) );
        }
    }
    ```

    This calls parent first (which handles all fields normally), then overwrites ONLY pos_auth_code with the raw value (wp_unslash removes magic-quotes slashes but preserves ALL characters including %, +, /, =). This ensures the auth code is never mangled by sanitize_text_field().

    **B. Load new settings into class properties** — In the constructor, AFTER the existing property loading block (`$this->title = ...`, `$this->description = ...`, `$this->enabled = ...`), add:

    $this->pos_id           = $this->get_option( 'pos_id' );
