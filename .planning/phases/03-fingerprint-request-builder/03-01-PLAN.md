1. **`vinti4_normalize_amount( float $amount ): int`**
   - Returns `absint( round( $amount ) )` — converts float order total to integer (e.g. 1500.99 → 1501).

2. **`vinti4_format_timestamp(): string`**
   - Returns `gmdate( 'Y-m-d H:i:s' )` — UTC timestamp in SISP-required format.

3. **`vinti4_build_merchant_ref( int $order_id ): string`**
   - Returns `'WC' . $order_id . '-' . gmdate( 'YmdHis' )` — unique per attempt (e.g. `WC42-20260416143022`).

4. **`vinti4_build_merchant_session(): string`**
   - Returns `'S' . wp_generate_password( 12, false, false )` — random alphanumeric session prefixed with 'S'.

5. **`vinti4_parse_order_id_from_ref( string $merchant_ref ): int`**
   - Extracts order ID from merchantRef pattern `WC{id}-...`.
   - Uses regex: `/^WC(\d+)-/` with `preg_match()`.
   - Returns `(int)` match on success, `0` on failure.

6. **`vinti4_shape_phone( string $phone ): array`**
   - Returns `['cc' => '', 'subscriber' => '']` with cleaned phone number.
   - Strips non-digit characters from input.
   - If length >= 9, last 9 digits = subscriber, remaining = cc (strip leading zeros).
   - If length < 9, all digits = subscriber, cc = empty string.

<task type="auto">
  <name>Task 2: Create Vinti4_Fingerprint class</name>
  <files>includes/class-vinti4-fingerprint.php</files>
  <action>
Create `includes/class-vinti4-fingerprint.php` with the `Vinti4_Fingerprint` class. Guard with `defined( 'ABSPATH' ) || exit;`. Add class existence check: `if ( class_exists( 'Vinti4_Fingerprint' ) ) return;`

The class has two static methods:

1. **`public static function sha512_base64( string $value ): string`**
   - Returns `base64_encode( hash( 'sha512', $value, true ) )`
   - The `true` parameter returns raw binary output from hash(), which is then base64-encoded.
   - This is the core hash primitive used twice in the fingerprint: once for posAuthCode, once for the concatenated base string.

2. **`public static function build_request_fingerprint( ... ): string`**
   Parameters (all strings, in exact order):
   - `$pos_auth_code` — POS auth code (will be SHA-512 hashed first)
   - `$timestamp` — formatted timestamp (yyyy-MM-dd HH:mm:ss)
   - `$amount` — integer amount (will be multiplied by 1000)
   - `$merchant_ref` — unique merchant reference
   - `$merchant_session` — session identifier
   - `$pos_id` — POS identifier
   - `$currency` — ISO 4217 numeric currency code
   - `$transaction_code` — transaction code (e.g. '1')
   - `$entity_code = ''` — optional entity code
   - `$reference_number = ''` — optional reference number
   - `$token = ''` — optional token

   Algorithm:
   ```
   $base = sha512_base64( $pos_auth_code )           // Hash the auth code first
         . trim( $timestamp )                         // Concatenate timestamp
         . (string) ( absint( $amount ) * 1000 )      // Amount × 1000 as string
         . trim( $merchant_ref )                      // Merchant reference
         . trim( $merchant_session )                  // Session
         . trim( $pos_id )                            // POS ID
         . trim( $currency )                          // Currency code
         . trim( $transaction_code );                 // Transaction code

   // Append optional fields ONLY if non-empty
   if ( '' !== $entity_code ) {
       $base .= (string) absint( ltrim( $entity_code, '0' ) ?: '0' );
   }
   if ( '' !== $reference_number ) {
       $base .= (string) absint( ltrim( $reference_number, '0' ) ?: '0' );
   }
   if ( '' !== $token ) {
       $base .= trim( $token );
   }

   return sha512_base64( $base );  // Hash the concatenated string
   ```

   CRITICAL: The field ordering in the concatenation MUST match SISP spec exactly. The first call to `sha512_base64()` hashes only the posAuthCode. The second call hashes the entire concatenated base string.

Add `@since 1.0.0` PHPDoc blocks. No namespace. Use WordPress coding standards (tabs).
